# Northline TMS — Frontend

React + TypeScript + Vite + Tailwind CSS + shadcn/ui single-page app. See the [root README](../README.md) for setup and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for structure.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://localhost:5080 (override with VITE_API_PROXY_TARGET)
npm run build    # type-check and production build to dist/
```
